# Sanaly Bet

Sanaly Bet is a frontend-only Next.js project about applied mathematics, probability, behavioral feedback, and ludomania prevention.

## Stack

- Next.js + React
- Tailwind CSS
- Recharts
- GSAP on `/particles-interaction`
- MediaPipe Hands JS on `/gesture-game`
- Canvas on `/spider-mind`
- `localStorage` persistence

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

MediaPipe needs camera permission and works best on `localhost` or HTTPS.
